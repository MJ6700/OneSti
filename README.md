## 📲 How to Install on Android

1. Download **`One_STI.apk`** from the link above to your Android phone.
2. Open the downloaded file from your **Downloads** folder or notification panel.
3. If prompted by Android with *"Install unknown apps"*, tap **Settings** and enable **"Allow from this source"**.
4. Tap **Install** and enjoy One STI!

## ✨ Features
- 🚀 **Butter-Smooth UI:** 60/120Hz high refresh rate display mode with native GPU compositor scrolling.
- 🔒 **Permanent Login:** Session tokens and cookies are permanently backed up so you never get logged out when closing the app.
- ⚡ **Anti-Inactivity Keep-Alive:** Automated background keepalive heartbeats prevent university portal session timeouts.
- 📱 **Edge-to-Edge Design:** Clean, distraction-free student portal view.
- 💾 **Integrated Download Manager:** Download schedules, grades, syllabi, and study materials straight to your device storage.
